# MediaSaver 媒体下载工具

支持 **抖音**（视频/图片无水印）和 **B站**（视频）下载。电脑上跑服务，手机和电脑都能用，外网也能访问。

| 平台 | 支持内容 | 提取方式 |
|------|---------|----------|
| 抖音 | 视频无水印 + 图文照片 | 浏览器渲染提取 |
| B站 | 视频（含画质选择） | API 直连 |

---

## 快速启动

### 方式一：家里用（同一 WiFi）

**推荐**：双击 **`start_server.bat`**
- 自动最小化窗口运行
- 浏览器打开 `http://localhost:8932`
- 手机连同一 WiFi，扫码页面上二维码即可访问
- 粘贴抖音/B站分享链接 → 回车解析 → 下载

### 方式二：出门用（手机 4G/5G 外网）

双击 **`start_tunnel.bat`**
- 自动启动本地服务 + Cloudflare 隧道
- 等待几秒，窗口会显示一个公网地址，例如：
  ```
  https://xxxxx.trycloudflare.com
  ```
- 手机浏览器打开这个地址，随时随地都能用

> ⚠️ 隧道地址每次重启都会变，分享给朋友后别关窗口

### 方式三：开机自启

把 `start_server.vbs` 快捷方式放到 `shell:startup`，开机自动运行（无窗口后台运行）。

---

## 启动脚本说明

| 文件 | 用途 | 说明 |
|------|------|------|
| `start_server.bat` | 启动本地服务 | **推荐**，最小化窗口运行 |
| `start_tunnel.bat` | 启动服务 + 外网隧道 | 会打开隧道窗口显示地址 |
| `start_server.vbs` | 静默后台启动 | 无窗口，适合开机自启 |
| `app.py` | Python 源码版 | 需要安装 Python |

启动脚本会自动按以下优先级查找：
1. `dist\MediaSaver.exe`（打包版）
2. `MediaSaver.exe`（打包版）
3. `python app.py`（源码版）

## 常见问题

**启动脚本闪退？**
脚本使用 GBK 编码，中文 Windows 正常显示。如果闪退，尝试直接双击 `start_server.bat`。

**exe 打不开 / 没反应？**
打包版 `MediaSaver.exe` 可能在某些系统上异常。改用 Python 启动（双击 `start_server.bat` 会自动检测并切换到 python）。

**提示「Windows 已保护你的电脑」？**
点击「更多信息」→「仍要运行」。

**下载的文件在哪？**
`MediaSaver_downloads` 文件夹。

**解析失败？**
① 链接已失效 ② 部分视频需登录才能看 ③ 网络不稳定。稍后重试。

**外网访问很慢？**
取决于你家宽的上行速度，数据从你的电脑传出去。

**怎么关闭？**
关掉命令行窗口即可。如果是最小化窗口，在任务栏找到关掉。
